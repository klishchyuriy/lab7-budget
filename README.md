# Лабораторна робота №7 (Web-технології): «Бюджет студента»

Кліщ Юрій, група ІА-401, КНЕУ, 2026

Односторінковий застосунок для обліку доходів і витрат за місяць.

- категорії завантажуються з `categories.json` через `fetch`;
- курси USD, EUR і PLN беруться з відкритого API НБУ, валютні суми перераховуються в гривні;
- форма з перевіркою полів, фільтри, пошук і сортування операцій;
- діаграма витрат за категоріями з місячними лімітами;
- дані зберігаються в `localStorage`, звіт можна завантажити у CSV;
- приклад даних у `demo.json`.

Сайт: https://klishchyuriy.github.io/lab7-budget/
